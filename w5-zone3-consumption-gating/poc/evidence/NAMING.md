# Evidence naming

Screenshot evidence for the Zone 3 gating POC. Capture every grid a script prints and drop the file in this folder.

| | |
|---|---|
| Naming | `<TC-id>_<short-slug>.png` — e.g. `TC-004_insert-overwrite-tags.png` |
| Two-session tests | suffix `_sessionA` / `_sessionB` |
| Several grids in one TC | suffix `_1` `_2` `_3`, in the order the script prints them |

Record each file against its TC in [`../Zone3_Gating_Test_Tracker.xlsx`](../Zone3_Gating_Test_Tracker.xlsx), **Evidence_Log** sheet.
