Our checks prove premium data is complete — not that it is right

Today's two controls, what they miss, and the problem to solve

Today's controls

ControlWhat it doesWhat it misses
Null checks on CDE columnsFlags blank values (informational — doesn't reject)A value that is present but wrong
Balance reconciliationProves source total = loaded totalWhether the source value was right

The problem to solve

We need a way to identify premium outliers and unusual trends — whether the business value itself is reasonable, and whether trends deviate from historical norms.

Why reconciliation isn't enough

Reconciliation asks: did we load everything we received?
A validity check asks: did we receive the right value in the first place?
Both scenarios pass reconciliation — we need a validity check (is the value reasonable?) alongside it.

ML anomaly detection can watch premium trends automatically

Snowflake ML Functions — how it works, what it needs, and which detector fits which job

How it works

  1. Train on history — e.g. weekly total premium per product line
  2. Forecast the expected range — learns weekly and yearly patterns itself
  3. Flag values outside the range — with forecast, bounds and distance
  4. Run on a schedule — a task runs it; an alert emails the team

Know before you go

  • Needs 12+ data points per series — 12 weeks (weekly) or 12 months (monthly)
  • Trains on historical data — can use premium history already in Snowflake
  • One sensitivity setting — default flags about 1% of values
  • Trained models can't be updated — retrain on a schedule
  • Can't flag anomalies inside its own training data — history must be clean

Three detectors, three jobs

JobBest toolReqNeeds
One policy's premium is wildly off (1,000 → 1,000,000)Custom outlier check (IQR) + expectationR3A threshold the business agrees (D1, D2)
This week's or month's premium total is out of lineML anomaly detectionR4 R512+ periods of clean premium history

Use the right detector for the job — a rule for single bad records, ML for weekly and monthly trends.
